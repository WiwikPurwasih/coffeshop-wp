# Coffeeshop WP ☕

Aplikasi web katalog menu kedai kopi sederhana yang dibangun menggunakan React dan Vite.

## 🧩 Komponen & Props

### `MenuKopi`
Komponen ini digunakan untuk menampilkan kartu produk menu kedai kopi.

**Props yang digunakan:**
- `nama` (String) : Nama produk/menu kopi (contoh: "Caffè Latte").
- `kategori` (String) : Kategori minuman (contoh: "Espresso Based").
- `harga` (Number) : Harga produk dalam Rupiah (contoh: 25000).
- `tersedia` (Boolean) : Status ketersediaan menu (`true` untuk Tersedia, `false` untuk Habis).
